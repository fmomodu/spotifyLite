# Spotify Lite Clone

A React recreation of Spotify's desktop interface created for CGT 390.

## Original Website

https://open.spotify.com/

## Technologies Used

- React
- Vite
- CSS
- React Icons

## How to Run

1. Clone the repository.
2. Run `npm install`
3. Run `npm run dev`

## Components

- Top Navigation
- Sidebar
- Main Content
- Right Panel
- Play Bar

## Current Features

- Spotify-inspired desktop layout
- Top navigation bar
- Sidebar navigation
- Playlist sections
- Right information panel
- Bottom music player
- Component-based React structure

## Future Improvements

- Functional search
- Responsive mobile layout
- Dynamic playlist data
- Music playback functionality
