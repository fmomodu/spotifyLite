# Spotify Lite Clone

A React recreation of Spotify's desktop interface created for CGT 390.

## Original Website

https://open.spotify.com/

## Technologies Used

- React
- Vite
- CSS
- React Icons

## How to Run

1. Clone the repository.
2. Run `npm install`
3. Run `npm run dev`

## Components

- Top Navigation
- Sidebar
- Main Content
- Right Panel
- Play Bar

## Current Features

- Spotify-inspired desktop layout
- Top navigation bar
- Sidebar navigation
- Playlist sections
- Right information panel
- Bottom music player
- Component-based React structure
- Dynamic playlist search and filtering

## Interactive Progress Update

### Interactive Feature

I implemented a search feature using React's `useState` hook. As the user types into the search bar, the playlists and artists are filtered automatically based on the entered text.

### Why I Chose It

Searching is one of Spotify's core features and demonstrates how React state and events can dynamically update the user interface.
